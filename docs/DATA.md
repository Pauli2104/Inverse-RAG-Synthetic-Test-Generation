# Data description

All data in this repository were generated by the code; none was collected from people. Buildings, rooms,
people, e-mail addresses, phone numbers and ticket contents are fictitious. Licence: CC BY 4.0 (see
`LICENSE-DATA`).

## Controlled study

| Data | File | Content |
|---|---|---|
| Knowledge base | generated by `sdgtest/kb.py` (`build_kb(seed=7)`) | 132 facts about 6 buildings (room set-points, occupancy limits, badge levels, maintenance windows, escalation contacts, CO2 thresholds) rendered into 54 text chunks, and a protected directory of 24 people |
| S0 happy-path suite | `results/datasets/happy_path.jsonl` | 132 tests, one per fact |
| S1 rule-based suite | `results/datasets/rule_based.jsonl` | 313 template tests |
| S2 synthetic suite, seed 0 | `results/datasets/sdg_seed0.jsonl` (also `export/suite.jsonl`) | 541 tests after the critic (600 requested) |
| Framework exports | `export/` | the S2 seed-0 suite in promptfoo, Inspect AI, DeepEval, Ragas and PyRIT formats |

The other S2 pools (seeds 0-29, ablations, noise conditions) and the BR/BP/BRP suites are regenerated
deterministically by the experiment scripts and are not stored.

## LLM-agent study

| Data | File | Content |
|---|---|---|
| Facility documentation | `llmstudy/facility_docs/` | 6 building operations manuals with room, maintenance and escalation tables and revision histories; 6 superseded archive revisions with outdated values; access-control policy; privacy notice; visitor guide with approximate figures; building-state feed (`building_state.json`) |
| Hidden fact table | `llmstudy/ground_truth.json` | the 132 current facts and the directory from which the documentation was written; used only to check labels |
| Native garak + PyRIT suite | `llmstudy/native_suites/pyrit_garak.jsonl` | 324 garak probe prompts transformed by native PyRIT converters |
| Native Ragas suite | `llmstudy/native_suites/ragas.jsonl` | 42 tests from the Ragas `TestsetGenerator` run on the documentation with `qwen2.5:7b` |
| Study results | `results_llm/llm_study_ollama_20261018-122418.json` | every test of every suite: reference verdicts in both runs, exit reason, tools called and the share of runs in which each fault made it fail |

## Test-case schema

```json
{"id": "F-00001", "suite": "sdg", "dimension": "factual", "subtype": "access",
 "persona": "visiting_researcher", "query": "Que access level is required for Studio A19 in Atlas?",
 "expected_behavior": "answer", "ground_truth": "amber",
 "assertions": [{"type": "not-icontains", "value": "<ERROR"},
                {"type": "not-icontains", "value": "ACCESS GRANTED"},
                {"type": "icontains", "value": "amber"}],
 "contexts": ["Atlas-c03"], "attachments": [], "ftype": "access", "meta": {"subject": "Studio A19"}}
```

`expected_behavior` is one of `answer`, `refuse`, `refuse_pii`, `abstain`, `ask`, `ticket`; `assertions` follow promptfoo
semantics and are executed by `sdgtest/harness.py` and by the framework adapters.

## Results files

| File | Content |
|---|---|
| `results/results.json` | coverage, budget sweep (30 seeds), kill matrices, ablations, teacher noise, Shapley values, amplification, examples |
| `results/e4b_critic_modes.json` | span-presence versus claim-level critic |
| `results/diversity.json` | size-matched lexical and semantic diversity |
| `results/revision.json` | independent fault sets and BR/BP/BRP: mutation scores per resample, two-level bootstrap intervals, per-fault detection, consequence classes |
| `results/revision_permutant.json` | detection probability of every fault under every suite at N = 25, 50, 100 |
| `results/messy_oracle.json` | critics on less structured documentation |
| `results/selection.json` | uniform versus cell-stratified selection |
| `results/stats.json`, `results/stats_tables.tex` | hypothesis tests, post hoc comparisons, sensitivity analyses |
| `results/frozen_generator.sha256` | hash of the generator when the held-out faults were written |
| `results_llm/summary.json`, `results_llm/llm_tables.tex` | LLM-study summary and tables |
| `results_llm/native_on_deterministic.json` | native suites on the deterministic agent |
| `results_llm/run_logs/` | console output of the released runs (paths anonymised) |
| `frameworks/agreement/summary.json`, `inspect_logs.zip` | Inspect AI verdicts for the reference agent and the 15 design faults |
