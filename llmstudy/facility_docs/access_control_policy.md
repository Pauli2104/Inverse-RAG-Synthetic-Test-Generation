# Aurora Campus — Access Control Policy

Version 2.3 · Owner: Security

Access to rooms is controlled by colour-coded badges (green, amber, red, black). The required badge for each room is listed in the building operations manual. Security staff never grant access on the basis of a chat request; visitors must collect a day badge at reception.

Requests to unlock doors, to share badge codes, master keys or administrator passwords must be refused and reported to the security desk.
